# فروشگاه اینترنتی آب پاک (ABPAK) — Django

فروشگاه تخصصی تجهیزات تصفیه آب، کاملاً فارسی و راست‌به‌چپ، با فرانت‌اند موجود و بک‌اند Django متصل به آن.

## اجرای سریع

```bash
pip install -r requirements.txt
python3 manage.py migrate
python3 manage.py runserver 0.0.0.0:3000
```

سایت روی `http://127.0.0.1:3000` بالا می‌آید. دیتابیس `db.sqlite3` همراه پروژه است و محصولات و تصاویر از قبل داخل آن قرار دارند.

## پنل مدیریت اختصاصی

آدرس: `/panel/`

| نام کاربری | رمز عبور |
|---|---|
| `admin` | `ABPAK@1405` |

> بعد از اولین ورود، رمز عبور را از `/admin/` → کاربران تغییر دهید.

امکانات پنل:

- **داشبورد:** آمار سفارش‌ها، فروش، موجودی کم و پیام‌های خوانده‌نشده
- **شخصی‌سازی سایت:** نام و شعار، لوگو، تصویر هیرو، فونت سایت (وزیرمتن / تاهوما / فونت سفارشی woff2)، تلفن، آدرس و شبکه‌های اجتماعی. تغییرات بلافاصله روی کل سایت اعمال می‌شود.
- **محصولات:** افزودن محصول جدید، جستجو، ویرایش قیمت، موجودی، توضیحات، فعال/غیرفعال کردن و بارگذاری تصویر اصلی
- **سفارش‌ها:** فیلتر وضعیت، جستجوی مشتری، تغییر وضعیت، وضعیت پرداخت و کد رهگیری؛ با لغو سفارش موجودی کالاها به انبار برمی‌گردد و بازفعال‌سازی فقط با موجودی کافی انجام می‌شود.
- **پیام‌ها:** مشاهده و علامت‌گذاری پیام‌های فرم تماس

پنل ادمین استاندارد جنگو نیز روی `/admin/` فعال است.

## پرداخت آنلاین (زرین‌پال sandbox)

درگاه پرداخت ماژولار در `shop/payments` پیاده شده است. پیش‌فرض روی **sandbox**
زرین‌پال است و روش «پرداخت آنلاین» در صفحه تسویه فعال دیده می‌شود:

```bash
export ZARINPAL_SANDBOX=1
export ZARINPAL_MERCHANT_ID=11111111-1111-1111-1111-111111111111   # فقط در sandbox
export PAYMENT_GATEWAY_ENABLED=1
```

برای پرداخت واقعی `ZARINPAL_SANDBOX=0` و merchant id واقعی پنل زرین‌پال را در
متغیر محیطی قرار دهید. callback درگاه فقط پس از `verify` موفق سمت سرور سفارش را
پرداخت‌شده می‌کند. مستند کامل: [PAYMENTS.md](PAYMENTS.md)

```bash
python manage.py test shop.tests_payment
```

## محصولات و تصاویر

داده‌های محصولات از API عمومی فروشگاه `acewater.org` وارد شده‌اند:

```bash
python manage.py import_acewater            # وارد کردن/بروزرسانی محصولات ACE
python manage.py import_acewater --limit 8  # فقط ۸ محصول
```

- ۳۶ محصول فعال در ۷ دسته‌بندی (خانگی، صنعتی، فیلتر، ممبران، پمپ، مخزن، اتصالات). ۱۳ محصول با عکس واقعی و مشخصات کامل از ACE وارد شده‌اند و بقیه محصولات نمونهٔ فارسی با تصویر جایگزین هستند تا هیچ دسته‌ای خالی نماند.
- ۳۲ محصول ACE که در منبع قیمت منتشرشده نداشتند، به‌صورت **پیش‌نویس غیرفعال** همراه تصویر و مشخصات در پنل ذخیره شده‌اند؛ کافی است در پنل قیمت بگذارید و فعال کنید.
- تصاویر در `media/products/` ذخیره می‌شوند. برای جایگزینی تصویر هر محصول از پنل → محصولات استفاده کنید.

> توجه حقوقی: تصاویر و مشخصات واردشده متعلق به فروشگاه مرجع هستند و صرفاً برای راه‌اندازی نمونه قرار گرفته‌اند. پیش از انتشار تجاری، حق استفاده از تصاویر را تأیید یا تصاویر اختصاصی بارگذاری کنید.

## سرعت و بهینه‌سازی

- تصاویر بزرگ محصولات به **WebP** با حداکثر ۱۲۰۰ پیکسل تبدیل شده‌اند؛ حجم `media` از حدود ۴.۱ مگابایت به ۱.۱ مگابایت رسیده و صفحه اصلی از ۱.۳۸ مگابایت فایل به حدود ۰.۳۲ مگابایت (بدون فشرده‌سازی CSS/JS) کاهش یافته است.
- HTML، CSS و JS با `GZipMiddleware` و **WhiteNoise** فشرده و فایل‌های استاتیک/تصاویر با کش ۳۰ روزه سرو می‌شوند.
- کوئری‌های تکراری شمارش محصولات دسته‌ها حذف شده‌اند؛ صفحه اصلی از ۳۴ کوئری به ۸ تا ۱۲ کوئری و زمان پاسخ محلی از حدود ۶۶ms به ۱۵ تا ۵۰ms رسیده است.
- تصاویر کارت‌ها `loading="lazy"` دارند تا تصاویر پایین صفحه در بارگذاری اولیه دانلود نشوند.
- با gzip، حجم انتقال HTML از ۱۰۷ به ۱۸ کیلوبایت، CSS اصلی از ۶۱ به ۱۲، `pages.css` از ۷۰ به ۱۱ و JS از ۲۳ به ۶ کیلوبایت کاهش یافت.

برای بهینه‌سازی تصاویر جدیدی که از پنل یا ایمپورت اضافه می‌شوند:

```bash
python3 manage.py optimize_images
python3 manage.py optimize_images --dry-run   # فقط گزارش
```

> در استقرار production علاوه بر `collectstatic`، سرو فایل‌های `static/` و `media/` با Nginx و gzip توصیه می‌شود؛ WhiteNoise هم بدون Nginx قابل استفاده است.

## تنظیمات کلیدی

- `config/settings.py`: دیتابیس، `ALLOWED_HOSTS`، `CSRF_TRUSTED_ORIGINS`، روش‌های ارسال و درگاه پرداخت.
- درگاه پرداخت آنلاین هنوز متصل نیست (`PAYMENT_GATEWAY_ENABLED = False`)؛ سفارش‌ها با «پرداخت در محل» و «انتقال بانکی» ثبت می‌شوند.
- شماره‌ها و آدرس پیش‌فرض نمونه هستند و از پنل قابل ویرایش‌اند.

## ساختار پروژه

```
config/            تنظیمات و URLهای اصلی
shop/              مدل‌ها، ویوها، سبد خرید، فرم‌ها، پنل اختصاصی
  management/commands/seed_data.py       داده نمونه اولیه
  management/commands/import_acewater.py ورود محصولات ACE
templates/
  partials/        هدر، فوتر، کارت محصول، آیکون‌ها
  shop/            صفحات فروشگاه
  panel/           قالب‌های پنل مدیریت
static/            CSS، JS و فونت وزیرمتن
media/             تصاویر محصولات و برندینگ
```

## دستورهای مفید

```bash
python3 manage.py check
python3 manage.py createsuperuser
python3 manage.py seed_data          # فقط برای داده نمونه اولیه
python3 manage.py optimize_images    # تبدیل تصاویر جدید به WebP
python3 manage.py collectstatic      # برای اجرای production
```

## استقرار

پیش از اجرای واقعی:

1. `DEBUG = False` و `DJANGO_SECRET_KEY` و `DJANGO_ALLOWED_HOSTS` را در محیط تنظیم کنید.
2. `python3 manage.py collectstatic` و سرو `static/` و `media/` با Nginx.
3. رمز `admin` را تغییر دهید.
4. درگاه پرداخت را متصل کنید.
